# Movie Recommendation System

## 📌 Overview
The **Movie Recommendation System** is a Python console application that recommends movies based on the user's preferred genre. Users can choose a genre, and the system displays a list of recommended movies. This project is designed for beginners to learn Python programming concepts such as dictionaries, lists, loops, functions, and user input handling.

## ✨ Features
- View available movie genres
- Get movie recommendations
- User-friendly console interface
- Multiple recommendations in one session
- Simple and beginner-friendly

## 🛠 Technologies Used
- Python 3
- Dictionaries
- Lists
- Loops
- Conditional Statements

## ▶️ How to Run
1. Install Python 3 on your computer.
2. Download or clone the project.
3. Open the project folder in VS Code or any Python IDE.
4. Run the program:
   ```bash
   python movie_recommendation.py
   ```
